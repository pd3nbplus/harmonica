# 守夜人口琴 · NIGHT WATCH HARMONICA

一个纯前端网页口琴模拟器：键盘当吹孔、鼠标当把位，打开浏览器就能吹。零依赖、零构建、纯静态文件。

> 主题来自游戏《三角洲行动》藏品「守夜人口琴」（藏品编号 NW-08），金黑配色的暗色复古界面。

## 快速开始

无需安装任何东西，任选一种方式：

**直接用浏览器打开 index.html**

```bash
# 方式一：直接用浏览器打开
open index.html        # macOS
xdg-open index.html    # Linux

# 方式二：起一个本地静态服务（推荐，体验最好）
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

首次按任意演奏键或点击页面后才会激活音频（浏览器自动播放策略限制，属正常现象）。

## 操作方式

### 演奏键（8 个音孔）

| 按键 | Z | X | C | V | B | N | M | , |
|------|---|---|---|---|---|---|---|---|
| 唱名 | do | re | mi | fa | sol | la | si | do |
| 音高 | C4 | D4 | E4 | F4 | G4 | A4 | B4 | C5 |

**按住发声，松开即止**，支持多键同时按（复音）。

### 把位修饰键（鼠标三键，像 Shift 一样按住生效，可叠加）

| 鼠标按键 | 效果 | 状态栏标识 |
|----------|------|-----------|
| 按住左键 | 整体降一个八度 | `↓ C3~C4` |
| 按住右键 | 整体升一个八度 | `C5~C6 ↑` |
| 按住中键 | 整体升半音 | `· 升半音 #` |

- 三个修饰键互不影响、可自由叠加；左键 + 右键同时按 = 回到原八度。
- 修饰键按下的瞬间，所有正在发声的孔会**平滑滑音**到新音高，松开立即还原。
- 页面已屏蔽右键菜单（右键是让位给升八度用的）。

## 四种玩法

1. **自由演奏**：直接按 `Z X C V B N M ,` 随意吹。
2. **跟弹引导**：选好曲目点「✋ 跟弹引导」，乐谱当前音符金色高亮、口琴上对应孔位呼吸闪烁，跟着按即可；按对自动前进，弹完整首提示完成。
3. **自动演奏**：点「▶ 自动演奏」试听曲目；**演奏中按任意键即可接管**，并从当前进度无缝切换到跟弹模式。
4. **录音回放**：点「● REC」开始录制（记下按键与八度/半音修饰），再按一次停止；「▶ 回放」原样重现，同样支持按键接管。

切窗口或页面失焦时会自动" panic "：停掉所有声音并复位修饰键，避免回到页面后出现卡音。

## 如何添加自己的歌

曲谱与逻辑分离，只需编辑 `songs.js`，在 `SONGS` 数组里加一项即可：

```js
{
  id: 'my-song',          // 唯一标识
  name: '我的歌',
  en: 'MY SONG',
  bpm: 90,                // 一拍的速度；时值以"拍"为单位
  notes: [
    ['Z',1],['X',1],['C',1],['Z',1],'|',   // 4 个音符 + 小节线
    ['B',2],['-',1],                        // sol 吹 2 拍，休止 1 拍
  ]
}
```

音符写法：

- **基本音符**：`'Z' ~ ','` 对应 8 个音孔，每个音符是 `[键, 时值(拍)]`，如 `['B',2]` = sol 吹 2 拍。
- **`|` 小节线**：不占时值、不发声，只用于乐谱分句显示。
- **`-` 休止**：占时值、不发声。
- **修饰记号**（写在键位上，可叠加）：
  - `X^` 升八度（如 `,^` = C6）、`X_` 降八度（如 `M_` = B3）
  - `#X` 升半音（如 `#V` = F#4）、`bX` 降半音（如 `bB` = F#4）
  - 组合示例：`#V_` = 低八度的 F#3

改完保存刷新页面即可，无需构建。

## 技术说明

- **零依赖**：纯 HTML + CSS + 原生 JavaScript，3 个文件，无框架无打包。
- **音频**：Web Audio API 实时合成——正弦基频 + 递减泛音模拟簧片、带通白噪声模拟气流、双 LFO 长音颤音，外加 tanh 波形饱和与压缩器增加"金属芯"。
- **音高系统**：MIDI 编号换算频率，修饰键改变的是全局偏移量，因此滑音、录音、自动演奏天然共享同一套逻辑。
